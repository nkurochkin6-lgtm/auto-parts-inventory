# Учёт автозапчастей

## О проекте
Локальное веб-приложение для учёта автозапчастей в небольшом магазине с двумя сотрудниками.

## Цель
Упростить учёт товаров и ускорить обслуживание покупателей.

## Основные функции
1. Учёт номенклатуры и остатков автозапчастей.
2. Просмотр истории продаж.
3. Повтор продажи или заказа из истории с проверкой актуальных цен и наличия товара.
4. Предупреждения о низком остатке товаров.

## План реализации
- Этап 1. Анализ требований и проектирование.
- Этап 2. Реализация повторной продажи из истории.
- Этап 3. Реализация уведомлений о низких остатках.
- Этап 4. Тестирование, повышение надёжности и подготовка релиза.
